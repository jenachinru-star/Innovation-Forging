# 编导工作台演进 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:subagent-driven-development 逐任务实施。步骤用 `- [ ]` 跟踪。

**Goal:** 在现有 56 测试基线上，把工作台演进为可离线运行、覆盖舞台排演筹备完整链路的跨媒介编导工作台。

**Architecture:** 保持 npm workspaces 单仓库与纯 JavaScript。确定性逻辑放 `shared/`，界面放 `client/src/components/`，远程 AI 仅作增强。比赛版全部能力可在无网络静态 `dist` 下运行。

**Tech Stack:** React 19 + Vite + Tailwind v4 + ECharts + Vitest；Express + Vitest；DeepSeek / Seedream（可选增强）。

## Global Constraints

- 纯 JavaScript ESM，不引入 TypeScript。
- 不引入路由库、状态管理库、数据库；持久化用 IndexedDB 并支持内存降级。
- 所有派生数据必须能回溯原文（`rawRange`）。
- AI 不可用时主链路必须完整可用，界面标注「仅本地处理」。
- 禁止外部字体/CDN；使用系统字体栈。
- 每任务结束必须 `npm test` 全绿并提交。
- 视觉：文本区浅色纸张感、媒体区深色、朱红仅用于关键动作与状态。
- 分支 `feat/director-workbench`；截止 2026-11-26。
- 已知技术约束：`shared/package.json` 的 `exports` 只映射了 `.` 与 `./diff.js`，新增子路径必须同步添加。

```js

第一场 老陈的客厅

  expect(scriptData.scenes[0].props).toContain('钥匙');
});
it('记录原文范围', () => {
  const { scriptData } = parseScriptOffline(TEXT);
  const r = scriptData.scenes[0].rawRange;
  expect(TEXT.slice(r.start, r.end)).toContain('老陈的客厅');

it('无结构文本给警告不抛错', () => {
```

- [ ] 实现要点：

```js
const ACT_RE = /^第[一二三四五六七八九十百\d]+幕/;
const SCENE_RE = /^第[一二三四五六七八九十百\d]+场\s*(.*)$/;
const CUE_RE = /^([^\s：:（）()【】]{1,12})[：:]\s*(.+)$/;
const DIR_RE = /^[（(【].*[）)】]$/;
const PROPS = ['钥匙','信件','信','信纸','钱','酒','酒瓶','照片','手机','伞','箱子','灯','花','书','药'];
```

逐行扫描并累计字符偏移；先收集「人物：」行建立候选角色表；幕标题切分 act；场标题切分 scene 并记录 `rawRange.start`；`CUE_RE` 命中且名称属于候选角色 → 台词，否则若整行像「名字+短句」仍记为台词并加 warning；`DIR_RE` → `stageDirections`；道具用 `PROPS` 在台词与说明中匹配；`presentCharacters` = 本场说话者 ∪ 说明中出现的人物名；`estimatedMinutes = max(1, ceil(台词字数/250))`；最终经 `normalizeScriptData` 输出，`meta.parser = 'offline'`。
