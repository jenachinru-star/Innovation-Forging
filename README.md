# 开排 · 舞台制作工作台

把零散创作素材与现有剧本整理成场次、人物、走位、技术提示、部门需求、排练影响和可交付材料。

## 核心链路

```text
剧本来源
  → 原文校对与场次解析
  → 场次 / 人物 / 道具拆解
  → 2D/3D 排演与 cue 绑定
  → 灯光 / 音乐 / 音响 / 舞美需求
  → 排练记录与修改影响
  → 视觉风格与制作资产
  → 排演包 / 部门单 / 剧本 / 项目归档导出
```

## 本地能力

- 多作品本地库，支持切换、重命名、归档导入和 `.kaipai.json` 导出。
- TXT、Markdown、Fountain 可直接在浏览器读取；DOCX 和可提取文字的 PDF 支持本地解析。
- 离线解析不依赖后端；每个作品首次启用外部文本 AI 需要明确授权，媒体生成仍需逐项确认。
- 2D 舞台支持角色拖动、AB 角、技术提示和台词绑定。
- 同一组位置数据可切换到 3D 白模预览并继续拖动演员。
- 视觉制作包含 10 个视觉族、24 位精选导演、结构化色彩比例和可复制提示词。
- 导出排演准备表、部门需求单、走位与提示、合并 HTML、Fountain 剧本。

## 本地运行

```powershell
npm install
npm.cmd run dev:server
npm.cmd run dev:client
```

仅使用本地核心时可以只启动客户端：

```powershell
npm.cmd run dev:client
```

## 构建与测试

```powershell
npm.cmd test
npm.cmd run build
```

构建产物位于根目录 `dist/`。项目使用 `base: './'`，可由静态服务器直接托管。

## 设计

视觉方向为”Worklight”：深色制作现场承托明亮工作纸，琥珀色标记 cue，朱红只表示风险或待确认。产品工作流全部使用中文；Fountain、PDF、cue、A/B 等保留必要专业标签。

## 当前边界

- 首版为本地单用户产品；实时多人协作、账号和云同步在后续阶段实现。
- 不做真实灯控、音频设备或多人排练现场同步。
- 图片和视频生成不是离线核心依赖；在线生成必须经过作品级授权和费用确认。
- 3D 目前支持白模预览、演员与基础道具的位置/旋转/缩放编辑，不模拟真实灯光、物理或复杂模型导入。
